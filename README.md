# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using **HTML5, CSS3, and JavaScript**, and deployed on **AWS S3** with **Amazon CloudFront** for fast, secure content delivery.

This project was developed as part of my **Summer Internship - Project 01**.

Build the image:

docker build -t portfolio-website .

Run the container:

docker run -d -p 80:80 portfolio-website

## ☁️ AWS Deployment

This project is deployed using:

- Amazon S3 (Static Website Hosting)
- Amazon CloudFront
- HTTPS Content Delivery

Deployment Workflow:

```
Local Development
        ↓
GitHub Repository
        ↓
Amazon S3 Bucket
        ↓
CloudFront Distribution
        ↓
Live Portfolio Website
```
